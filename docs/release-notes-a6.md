## 1.11.0-a6

- **Значок «T» рядом с часами.** Значок уведомления перерисован: теперь это «T» с круглыми концами, который хорошо читается в строке состояния. Пока прокси работает, он висит рядом с часами — это видно и когда приложение свёрнуто. Значок появляется и исчезает вместе с прокси: он часть постоянного уведомления foreground-сервиса.
- **Подсказка, если уведомления выключены.** Если уведомления приложения запрещены (или отключён канал «Состояние прокси»), значка «T» не будет по определению. Теперь на главном экране появляется строка «Уведомления приложения выключены…» и кнопка **«Настройки уведомлений»**, которая открывает нужный системный экран.
- **Починена кнопка «Оригинальный проект».** Раньше на узких экранах надпись рвалась по буквам («Оригинальны / й проект»). Теперь перенос строго по словам — «Оригинальный / проект», «Форк на / GitHub»; для этого в подписях стоит явный перенос, у кнопок уменьшены внутренние отступы, а у диалога — боковые поля.

Пакет `com.nixikon.tgwsproxy`, версия `1.11.0-a6` (versionCode 12), ABI `arm64-v8a` + `x86_64`.

Обновление ставится поверх `a5` — при запуске приложение само предложит скачать эту версию.
