## 1.11.0-a8

Разобрался подробнее, почему звонки не работают, и добавил в приложение проверку, которая отвечает на этот вопрос предметно.

- **В диалог «Звонки через прокси» добавлен раздел «Как проверить, в чём дело»**: отключить прокси в Telegram и позвонить; посмотреть строку `call path` в диагностике; снять лог во время неудачного звонка («Логи» → «Поделиться»).
- **В «Диагностике» появилась строка `call path`** — проверка, дотягивается ли телефон до серверов Telegram **напрямую, без прокси** (`DC2 149.154.167.51:443`, `DC203/call 91.105.192.100:443`). Это ключевой вопрос для звонков: медиа звонка идёт по UDP мимо прокси и не может быть перенесено через WebSocket, поэтому звонки зависят только от прямого пути. Проверка только TCP — медиа часть по UDP так не проверить, о чём в строке прямо сказано.
- В тексте пояснения уточнено: **у Telegram для Android вообще нет переключателя «звонки через прокси»** (в актуальном клиенте такой строки нет), то есть клиент никогда не отдаёт звонок прокси — прокси звонкам не мешает, но и помочь им не может.

На эмуляторе в сети этой машины проверка показала `unreachable` для обоих адресов: прямой доступ к серверам Telegram закрыт, работает только прокси — ровно та ситуация, в которой звонки без VPN невозможны.

Пакет `com.nixikon.tgwsproxy`, версия `1.11.0-a8` (versionCode 14), ABI `arm64-v8a` + `x86_64`.

Обновление ставится поверх `a7`.
