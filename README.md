# TG WS Proxy for Android

Android-приложение (APK) — форк проекта [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) автора **Flowseal**.

Ядро MTProto-прокси — код оригинального проекта, по возможности сохранённый побайтово. Android-часть (интерфейс, foreground-сервис, мост в Python через Chaquopy) написана заново.

## Сборки

Готовые APK — в разделе [Releases](../../releases/latest). Приложение само проверяет обновления при запуске и предлагает установить новую версию.

## Установка

1. Скачайте APK из Releases.
2. Разрешите установку из этого источника (Android спросит один раз).
3. Откройте приложение, нажмите «Запустить», затем «Открыть в Telegram».

## Возможности

- локальный MTProto-прокси с передачей трафика Telegram через WebSocket;
- мультиплексирование медиа по HTTP/2 через Cloudflare;
- плитка в «быстрых настройках» и постоянное уведомление;
- настройки: порт, secret, датацентры, CF-прокси и CF Worker, пул сессий, логи;
- русский и английский интерфейс;
- проверка обновлений внутри приложения.
